📋 Proiect ANGELLI — Sistem de gestiune pe rețetar

Document viu — se actualizează pe măsură ce avansăm și primim feedback de la Bogdan. Ultima actualizare: 17 august 2026 seara. Autor: Eugen + AI Claude.

🎯 Ce vrem să obținem

Un sistem care răspunde zilnic la 3 întrebări fundamentale:

  • Cât stoc am REAL vs TEORETIC? — detectare furt, risipă, erori rețetar
  • Cât profit real am pe fiecare produs vândut? — marja adevărată, nu cea presupusă
  • Ce trebuie să comand mâine ca să nu rămân fără marfă? — comenzi sugerate automat

Piese existente pe care ne bazăm: rețetarul (40 rețete), vânzări Selio, facturi intrare, inventar făcut de Alex.

✅ Ce e gata deja

  • Aplicație live: arafura-store.github.io/angelli
  • Modul Casă — intrări + ieșiri cash/card pe centre (bucătărie / bar / general)
  • Filtre pe perioadă (azi / săptămâna / luna / interval custom) și pe tip tranzacție
  • Utilizatori: Eugen + Bogdan (mod testare, fără PIN deocamdată)
  • Paleta ARAFURA (navy + gold + sidebar închis)

Estimare: 2-3 zile de construit + timp de introducere date de la Bogdan

Ce construim în aplicație:

  • Pagina Ingrediente — Bogdan introduce cele ~100 ingrediente:
    • Nume, unitate măsură (kg, L, buc)

  • Pagina Furnizori — Metro, Selgros, distribuitori bere, măcelar, aprozar, etc.

🔌 Cerințe API Selio — ce trebuie să întrebe Bogdan

Bogdan contactează suportul Selio (sau vânzătorul lor) și cere concret:

📞 Text sugerat pentru discuția cu Selio:

"Bună ziua, folosim Selio la restaurantul ANGELLI. Ne construim o aplicație internă pentru gestiune stocuri și dorim să extragem automat, o dată pe zi, datele de vânzări din Selio. Vă rog să-mi confirmați:"

  1. Aveți API REST public disponibil pentru clienți? Dacă da:
    • URL documentație API
    • Cum obținem o cheie API (proces + costuri)
    • Există un sandbox / mediu de test?
  2. Ne interesează exclusiv o cheie API cu permisiuni READ-ONLY (doar citire). Nu vom scrie nimic în Selio, doar citim.
  3. Ce date putem citi zilnic:
    • Total încasări zi (cash + card, separat)
    • Detaliu vânzări per produs (cod produs Selio + cantitate + preț unitar + preț total) — ideal pentru fiecare zi
    • Categorii produse (bar / bucătărie / desert)
    • Bonus (dacă permite): detaliu vânzări per masă / comandă / oră
  4. Frecvență apeluri: 1 apel/zi maxim (după închiderea restaurantului). Nu avem nevoie de real-time.
  5. Format răspuns preferat: JSON. Acceptăm și XML sau CSV.
  6. Rate limits / costuri per apel?

Dacă răspund că NU au API sau că e complicat:

Nu blocăm proiectul. Alternativa: export CSV / Excel manual — Bogdan (sau casierița) apasă un buton în Selio seara, salvează un fișier, îl încarcă în aplicația noastră. Adaugă ~1 minut de muncă manuală pe zi, în rest merge la fel.

🔄 Workflow zilnic complet — cum va funcționa

  1. Dimineața (înainte de deschidere): Bogdan primește pe telefon lista de comandă sugerată per furnizor. Doar apasă → email / WhatsApp gata pregătit → trimite. Estimat: 2 min/zi în loc de 30 min de gândit + telefonat.
  2. În timpul zilei: Vânzările curg în Selio (ospătarii nu simt nicio schimbare). Când vine marfă, factura ajunge pe adresa dedicată facturi@angelli.ro.
  3. Seara (după închidere): Sistem citește vânzările din Selio (auto sau CSV import), aplică rețetarul → calculează consum teoretic per ingredient → actualizează stocul teoretic live.
  4. Săptămânal (vineri seara, ~20 min): Alex face inventar la ingredientele scumpe direct pe telefon. Sistem compară cu teoretic. Diferență mare → alertă imediată Eugen + Bogdan.
  5. Lunar (ultima seară, ~2h): Alex face inventar complet la toate ingredientele. Raport clar în dashboard cu diferență totală valorică.
  6. Când vine factură pe email: AI extrage automat furnizor + articole + cantități + prețuri → Bogdan aprobă (doar dacă e ingredient nou / furnizor nou) → stoc + preț achiziție se actualizează instant.
  7. Când apar anomalii: Sistem detectează automat "consumi ×2 mozzarella față de media" → alertă → verifici bucătarul / rețetarul.
